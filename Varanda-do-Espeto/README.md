# Varanda do Espeto

Landing page estática em HTML, CSS e JavaScript. As imagens ficam em `assets/`.

## Publicar pelo GitHub e Vercel

1. Crie um repositório no GitHub e envie **o conteúdo desta pasta** para a raiz dele (`index.html`, `assets/` e `README.md`).
2. Na Vercel, escolha **Add New → Project**, importe o repositório e clique em **Deploy**. Não é necessário comando de build nem framework.
3. Depois de publicar, confira os botões de WhatsApp e rota. O conteúdo e as imagens ilustrativas podem ser atualizados editando `index.html` e `assets/`.

As imagens `picanha-ilustrativa.png` e `tropeiro-ilustrativo.png` foram geradas como ilustrações. As demais fotos de pratos e bebidas foram fornecidas para este projeto.
