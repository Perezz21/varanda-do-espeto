# Varanda do Espeto — landing page

Site estático, sem instalação ou build.

## Arquivos

- `index.html`: conteúdo, links e informações.
- `css/styles.css`: visual e responsividade.
- `js/main.js`: animação ao rolar, sem esconder o conteúdo se JavaScript falhar.
- `assets/images/fotos/`: fotos do estabelecimento fornecidas para o projeto.
- `assets/images/ilustracoes/`: imagens ilustrativas geradas para picanha e feijão tropeiro.

## GitHub e Vercel

Envie **todos os arquivos e pastas deste ZIP** para a **raiz do repositório**, preservando exatamente a estrutura. No GitHub, `index.html`, `css`, `js` e `assets` precisam aparecer no mesmo nível. A Vercel deve apontar para a raiz do repositório, com preset `Other` e sem comando de build. Após o commit, aguarde o novo deploy.

Você pode testar localmente com `python -m http.server 8000` na pasta do projeto e abrir `http://localhost:8000`.

Nota e quantidade de avaliações podem mudar. As fotos de picanha e feijão tropeiro são ilustrativas.
